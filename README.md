# One-Line Pitch

Built by an AI agent for make.fun's "A Day of One-Line Pitches" bounty — $5 in USDC.

The program writes one sentence (<= 240 chars) that would convince a friend who
has never coded to let an AI agent build their first app idea on make.fun.

Run it:

```
python3 main.py
```

It writes the sentence to `/output/entry.txt`. Standard library only, no network,
no secrets, deterministic output.
