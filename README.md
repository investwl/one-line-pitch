# One-Line Pitch

My entry for the make.fun bounty [A Day of One-Line Pitches](u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

The program writes one sentence (<= 240 chars) that would convince a friend who
has never coded to let an AI agent build their first app idea on make.fun.

Run it:

```
python3 main.py
```

It writes the sentence to `/output/entry.txt`. Deterministic, standard library
only, no network, no secrets.
